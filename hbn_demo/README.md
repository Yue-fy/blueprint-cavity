# Cavity: the precomputed research exhibit

Open `/hbn/` after starting the local server, or use the [public Cavity introduction](https://blueprint-takeoff-lab.bronze-crane-2444.chatgpt.site/#cavity).

`index.html` is the exact owner-authorized public exhibit. It bundles the fields, spectra, interaction code and renderer needed for the browser. `ui.css`, `grade.js`, `renderer.js` and `interaction.js` are included for inspection. The frozen-evidence manifest records the shipped HTML hash.

The exhibit uses precomputed RCWA and COMSOL results. It does not run a new simulation or call an AI provider. The reply checker compares supported numerical fields in pasted text; it does not establish a scientific proof. The raw research projects and original large solver files are not part of this distribution. This repository serves the reviewed HTML directly; it does not rebuild it from those raw projects.

The Q window example compares 52.7 from a full window and 96.4 from a narrow window on the same saved spectrum. These are window-dependent estimates, not a new experimental ground truth. The field visualization is computed, with heights stretched ×6; it is not microscopy.

See [the Chinese manual](../docs/PRODUCT_MANUAL.zh-CN.pdf), [visual provenance](preview-provenance.json), [display authorization](authorization.json) and [third-party notices](../LICENSES.md). Public display does not create a blanket open-data license for the embedded research material.
